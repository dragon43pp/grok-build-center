# Grok Build Pager · 设计规范

> 一页看完。改任何视觉之前先读这个。

## 一、名字

**Grok Build Pager** —— 呼机。

你开了六个 Grok Build，去泡了杯咖啡。回来的时候不知道哪个卡在等你点确认。
这东西替你盯着，**卡住了就呼你**。

它不是「dashboard」（仪表盘，你得盯着它），是 **pager**（传呼机，它来叫你）。
这个区别决定了整个产品的语气：**不要求你持续关注，只在该打断你的时候打断你。**

仓库名 `grok-build-pager`。前面那截 `grok-build-` 不是装饰 —— GitHub 上
`grok-build-vscode` / `grok-build-switch` / `grok-build-auth` 是这个生态的搜索命名空间，
搜 `grok build` 能命中，这是引流的一部分，别改。

> 为什么不用 `grok-build-deck`：`grokdeck`(5★) 和 `grok-deck`(1★) 已经被人占了，
> 撞名会分流搜索。名字要独占。

## 二、唯一的设计原则

> ### 一张图里，只有一颗灯是亮的。

这不是比喻，是硬规则。所有视觉都服从它。

理由：这个产品解决的问题是**信息过载**（几百场会话里找出该看的那一场）。
如果视觉先过载了，产品说什么都白搭。所以画面里永远只有**一个**高饱和、带光晕的元素，
其余全部退到灰蓝。你扫一眼，视线自动被那一点抓住 —— 这正是用这个工具时的动作。

**一条推论**：logo 里可以有多个槽位（说明「多个会话」），
但**图标里只留一颗灯**。图标要在 16px 下被认出来，多一颗灯就糊一分。
「多个会话」是产品的信息量，不该塞进图标。

配套的细节规则：

| 规则 | 为什么 |
| --- | --- |
| 全图只有一个元素带光晕 | 光晕是「看这里」的信号，用两次等于没用 |
| 不用阴影、不用立体斜角 | 这是仪器面板，不是 App Store 截图 |
| 圆角只有两档：小元件 2–10px、大容器 14–22px | 中间档的圆角会让界面看起来「没想清楚」 |
| 分隔一律 1px 发丝线，颜色 `--hair` | 靠线分块，不靠背景色差 |
| 一屏只允许两档字号：很大 和 很小 | 仪表盘的语言。中间字号 = 没重点 |

## 三、色板

### 底与字

| 用途 | 变量 | 深色 | 浅色 |
| --- | --- | --- | --- |
| 背景 | `--bg` | `#0B0E13` | `#F5F7FA` |
| 面板 | `--plate` | `#141922` | `#EDF0F5` |
| 屏幕内嵌 | `--screen` | `#0E1218` | `#E7EBF2` |
| 分隔线 | `--hair` | `#242C38` | `#DFE4EC` |
| 主文字 | `--ink` | `#E8EBF0` | `#0F1420` |
| 次要文字 | `--dim` | `#8A93A3` | `#626C7D` |
| 极次要 | `--faint` | `#5E6675` | `#98A1B0` |

默认走**深色**。不是「因为深色好看」，是因为用户的眼睛本来就活在深色终端里，
切到浅色面板会刺眼。浅色模式是给 GitHub 上白天看 README 的人准备的。

### 状态灯（六色，不要再加）

| 状态 | 色值 | 含义 |
| --- | --- | --- |
| `working` | `#F2A93B` 琥珀 | 正在输出，别管它 |
| `needs-you` | `#FF6B4A` 珊瑚 | **卡在等你确认 —— 只有它会发光** |
| `done` | `#3ECF8E` 薄荷 | 跑完了，可以收结果 |
| `error` | `#EF4E45` 绛红 | 炸了，需要人介入 |
| `idle` | `#6B7484` 石板灰 | 活着但没动静 |
| `exited` | `#4C9AFF` 天蓝 | 进程退了，历史里还能捞回来 |

**珊瑚 `#FF6B4A` 是全场唯一会发光的颜色。** 它同时是品牌色。
这种复用是故意的：这个产品大部分时间，你的会话都在跑；而它唯一想让你动的，
就是那一颗珊瑚灯。

### 为什么辉光只给珊瑚

`#FF6B4A` 之外的颜色（琥珀、薄荷、绛红）在 UI 里**只以实心圆点出现，不带光晕**。
光晕是稀缺资源，滥用之后「一眼抓到重点」就失效了。

### 离线报告里怎么用（`tools/sessions_html.py`）

会话管理台是一整页几十场会话，灯会**同时出现好几颗** —— 这是唯一允许的例外，
但规则没变：**只有「正在运行」那一场是珊瑚 + 光晕 + 左侧珊瑚边条**。

代码漂移这类警示**故意不用珊瑚**，走中性琥珀（`#B4741A` 字 / `#FFF8EC` 底 / `#F0DCB4` 边）。
理由：漂移很常见（本机 41 场里有 5 场），如果它也发光，页面就会变成一片橙，
「哪一场在跑」这个第一眼信息立刻被淹掉。**警示敢用中性色，是因为它不需要抢注意力，
它只需要被读到。**

## 四、字体

- 标题 / 正文 —— 几何无衬线：
  `ui-sans-serif, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial`
- 数据 / 路径 / 状态名 / 命令 —— 等宽：
  `ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace`

> **凡是机器给的东西一律等宽。** 路径、时长、状态名、恢复命令 —— 全部。
> 这是区分「我写的」和「它跑出来的」最快的办法，尤其在中文混排里。

字距规则：小型全大写标签（`GROK BUILD`、`LOG · RESUME · SEARCH`）
一律拉开 `letter-spacing: 3.4px` 以上；大标题反而要压紧（`-1.6px`）。
**「小字拉开、大字压紧」是铭牌式排版的骨架。**

## 五、排版骨架：铭牌

品牌 lockup 不用「logo 在左、字在右」的常规排法，用**产品铭牌**的结构：

```
GROK BUILD            ← 小、等宽、字距拉开、灰
Pager                 ← 大、粗、字距压紧、白
─────────────
会话卡住了，它呼你。      ← 一句话价值主张
LOG · RESUME · SEARCH · FEISHU
```

「上小下大」比水平并列更有物件感 —— 像刻在机器上的铭牌，而不像一张广告。

## 七、图标是怎么来的

`tools/make_icon.py` —— 纯 Python，零依赖，4 倍超采样 + 盒式降采样，
自己写 PNG（zlib）和 ICO（内嵌 PNG）编码。

```bash
python tools/make_icon.py            # 重新生成
python tools/make_icon.py --verify   # 校验 ico 结构
```

为什么不画成 SVG 了事：Windows 的开始菜单、任务栏、文件关联都吃 `.ico`，
而 `.ico` 要的是位图。为了这一个需求装 Pillow 不划算，
几何又简单到可以手画（圆角方板 + 一颗灯 + 一条槽），所以自己算。

**这个图标是我们自己的，不要换成别的项目的图标。**

## 八、出图（gpt-image-2）

```bash
python tools/gen_assets.py            # 全量
python tools/gen_assets.py --list     # 看有哪些
python tools/gen_assets.py app-icon   # 单个
```

提示词在 `assets/prompts.json`：`style` 字段是公共前缀，改风格只改那里。
里面已经写死了「一张图只能有一颗灯亮」和「不要出现任何字母」两条约束。

需要先登录 l0veyou.com（双击桌面 `chutu2-login` 快捷方式）。没登录会明确报错，
不会静默出废图。

## 九、不能做的事

- **不要给状态灯加第七种颜色。** 要加状态就复用现有色 + 改形状（空心 / 环 / 半环）。
- **不要让第二个元素发光。** 包括按钮、边框、hover 态。要强调就改亮度，不要加光晕。
- **不要用紫色渐变。** 这是终端工具，不是 AI 营销页。
- **不要在浅色模式用 `#FF6B4A` 做正文色**（对比度不够），浅色下改用 `#C8452A`。
- **不要往 logo 或图标里加字。** 名字在 lockup 里有，图标里没有。
- **不要把 `grok-build-` 前缀改掉。** 那是搜索入口。
