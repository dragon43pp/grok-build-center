# Grok Build Center · 前端设计施工规格（DESIGN-SPEC）

> **这份文档给谁**：负责把界面「从 HRack 换皮变成 Grok Build Center」的实现者
> （人或 agent）。设计哲学与色板定义在 `docs/brand.md`，那是「宪法」；
> 本文档是「施工图」—— 把宪法翻译成每一页、每一个组件的落地指令。

## 〇、现状诊断：哪里还像 HRack

产品身份已经换完（包名 / userData / 管道 / 图标 / 字标），但**视觉结构**仍是上游
HRack 的「多 CLI 终端管理器」骨架。具体五处：

| # | HRack 残留 | 问题 |
| --- | --- | --- |
| 1 | **左侧 IconRail（竖排图标工具栏）+ 顶部 TopTabBar 双导航** | 终端管理器的导航密度；两个导航层在抢注意力，违背「只有一颗灯亮」 |
| 2 | **信息架构以终端为中心**：开屏直进终端页 | 产品定位是「会话中心」——用户第一眼该看到的是「哪场在跑、哪场卡住」，不是一块黑终端 |
| 3 | **会话状态弱**：状态灯小、藏在标签里 | 产品的核心价值（卡住主动找你）在视觉上不可见 |
| 4 | **通用 Electron 壳**：系统标题栏 + 表单式设置页 | 没有铭牌感，和任何 Electron 工具无差别 |
| 5 | **设置页是长表单** | 上游功能堆叠的痕迹；应改为分区卡片 + 明确的「连接状态」叙事 |

## 一、目标体验（一句话）

**一台仪器面板，不是一块软件。** 深色金属底、发丝线分块、等宽字标注仪表读数；
整块面板只有一颗珊瑚灯在亮 —— 那就是卡住等你确认的那场会话。

三条可执行的判据（验收时逐条问）：

1. **截掉文字，用户还能一眼指出「哪场会话需要我」。** 指不出 = 不合格。
2. **任何时刻全屏只有一个元素带光晕。** 出现第二个 = 不合格。
3. **机器产出的字符（路径/时长/命令/模型名）全部是等宽字体。** 出现宋体感的路径 = 不合格。

## 二、设计令牌（已就位，实现者只许引用、不许另造）

主题系统由 `shared/theme-schema.ts` 一处生成，前缀 `--gbc-`。核心值：

| 变量 | 深色（默认） | 浅色 |
| --- | --- | --- |
| `--gbc-bg` | `#0B0E13` | `#F5F7FA` |
| `--gbc-plate` | `#141922` | `#EDF0F5` |
| `--gbc-screen` | `#0E1218` | `#E7EBF2` |
| `--gbc-hair` | `#242C38` | `#DFE4EC` |
| `--gbc-ink` | `#E8EBF0` | `#0F1420` |
| `--gbc-dim` | `#8A93A3` | `#626C7D` |
| `--gbc-faint` | `#5E6675` | `#98A1B0` |
| 珊瑚（品牌/needs-you） | `#FF6B4A`，唯一带光晕 | 同 |
| 琥珀 working / 薄荷 done / 绛红 error / 石板 idle / 天蓝 exited | 见 brand.md 第三节，实心圆点、**不带光晕** | 同 |

补充规格（brand.md 未覆盖，本文新增）：

- **间距**：4px 网格。页边距 24，卡片内边距 16，元件间隙 8/12 两档。
- **圆角两档**：小元件（灯、徽标、按钮）2–10px；大容器（卡片、面板）14–22px。**禁止中间档**。
- **发丝线**：所有分块用 `1px solid var(--gbc-hair)`；**不用背景色差分块**，不用阴影。
- **动效**：`150ms ease-out`（hover/按压）、`250ms ease-out`（页面切换、抽屉）；
  唯一的循环动画 = needs-you 灯的呼吸光晕（2s 循环，透明度 0.6→1）。
  除光晕外**不做任何位移动画**超过 8px。
- **焦点**：键盘焦点环 `2px solid #4C9AFF`（天蓝），偏移 2px。这是天蓝唯一的交互用途。
- **字重门禁**：PingFang 三档字重已有构建门禁（`assert-font-size.mjs`），改动勿超 416380 bytes。

## 三、信息架构重排（施工的第 0 步）

```
改前（HRack）:  IconRail ─ TopTabBar ─ 终端页(默认)
改后:           左侧「会话列」恒驻 ─ 右侧主区按需切换
```

- **左侧栏改造成「会话列」**：不再是图标工具栏，而是常驻的会话清单 ——
  每行 = 状态灯 + CLI 徽标 + 会话名。这是产品的「仪表读数区」。
  宽度 240px，可折叠成 48px 图标条（此时每行只剩灯 + CLI 徽标）。
- **顶部只留一层**：窗口级标题栏（自绘，含字标铭牌 + 全局搜索 + 设置齿轮）。
  TopTabBar 的「多标签」语义并入左侧会话列（点会话行 = 切换主区）。
- **主区四种内容**：终端（点某场会话进入）/ 首页总览 / 历史 / 统计。设置走独立路由，不占导航位。

## 四、组件规格

### 4.1 状态灯（全产品最重要组件）

- 形态：10px 圆点；needs-you 时 12px + 光晕（`box-shadow: 0 0 12px 2px rgba(255,107,74,.45)`）+ 呼吸。
- 六态语义见 brand.md。**灯旁永远跟等宽状态词**（`working` / `needs-you` …），小号全大写、字距 1px。
- 光晕同时是路由信号：点击发光的行 = 直接跳到那场会话的终端。

### 4.2 铭牌 lockup（首启页 / 首页空态 / 标题栏）

```
GROK BUILD        ← 11px 等宽 · letter-spacing: 3.4px · --gbc-dim
center            ← 字标 Ammonite「center」· 34px · 压紧 -1.6px · --gbc-ink
──────────────    ← 1px 发丝线，宽度 = 文本宽
一场不漏，卡住的那场会主动找你。   ← 13px · --gbc-dim
```

### 4.3 会话行（左栏 / 历史页 / 总览页复用同一组件）

```
[●] [grok]  造书成剧 · 首页改版          ← 灯 10px · CLI 徽标等宽 10px · 标题 13px
              D:/wx/造书成剧 · 3m        ← 11px 等宽 · --gbc-faint
```

- 悬停：背景从透明 → `rgba(255,255,255,.03)`；**禁止**整行变色高亮。
- 选中：左侧 2px 珊瑚边条（仅当前打开的会话）；运行中那场用琥珀边条。
- 不可恢复的会话（如 WorkBuddy）：灯位换 `--gbc-faint` 空心圈，行尾「查看」二字，**不写「恢复」**。

### 4.4 终端页

- 终端容器 `--gbc-screen` 内嵌于 `--gbc-plate` 面板，四周 12px 呼吸，1px 发丝线包边。
- 终端上方一条 32px 会话信息条：状态灯 + 模型名 + cwd + 本次耗时（全部等宽）。
- xterm 主题色板须从 `--gbc-*` 派生，**禁止**上游默认配色残留。

### 4.5 设置页

- 改为分区卡片：`外观` / `CLI 连接` / `飞书` / `远程` / `关于`。
- 每张卡头：小型全大写标签（字距 3.4px）+ 一行状态（如飞书卡头右侧「已连接 · 绿点」）。
- CLI 连接卡：每个 CLI 一行会话行式布局（灯 + 名 + 检测路径），检测失败行内联 11px 等宽错误，不用弹窗。

### 4.6 悬浮窗 & 飞书卡

- 悬浮窗沿用「一颗灯」规则：只显示 needs-you 的会话，没有则整窗降到 40% 透明度。
- 飞书卡片是「手机的仪器面板」：同一个状态灯语义、同一块珊瑚；标题用铭牌结构。

## 六、实现者工作协议

1. **顺序**：令牌核对 → 信息架构（第三节的左栏改造）→ 状态灯组件 → 逐页。前面没稳住不碰后面。
2. **自验**：每完成一页，深浅两主题各截一张图；对着第一节三条判据自检。
3. **禁区**：
   - 不引入新 UI 依赖（无组件库、无图标包；图标走 `src/app/adapterIcons.ts` 既有 lucide 引入方式）；
   - 不动 `shared/theme-schema.ts` 的变量名（只许加，不许改名）；
   - 不碰 `tools/rebrand.mjs` 审计白名单（不许让 hrack 字样回流）；
   - 不做超过 8px 的位移动画、不加第二种光晕。
4. **完成的定义**：typecheck / build / 三个判卷脚本全绿 + 深浅截图各一张 + 三条判据逐条通过。
